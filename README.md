# Avoid Rain Assets

This repository contains the creative assets (graphics, music, and sound effects) for **Avoid Rain**, a noir roguelite set within a shifting manuscript.

## Licensing

See [LICENSE](./LICENSE) for details.

## Structure
- `audio/music/`: Atmospheric OGG tracks for the macro-world and Sanctuary.
- `audio/sfx/`: Tactile sound effects for combat and environmental hazards.
- `graphics/`: (Planned) PNG sprites and tilesets for the Scriptorium Noir aesthetic.
